# quarry: biology

Use `--domain biology` (or set `domain = "biology"` in `quarry.toml`). This domain includes `core`.

## Which resource answers what

- Deposited data: GEO (`geo`), ENA (`ena`), BioStudies (`biostudies`). `search` covers these by default.
- Terms: Gene Ontology (`go`), UBERON anatomy (`uberon`), NCBI Taxonomy (`ncbitaxon`) through `term search|show|ancestors`.
- Literature: PubMed (`pubmed`) and Europe PMC (`europepmc`), not in the default set; name them with `--in pubmed`.
- Term ids need their prefix: `go:`, `uberon:`, `ncbitaxon:`.

## Organism

`--organism` takes a taxon name or an `ncbitaxon:` CURIE and is applied per resource. GEO and
ENA include subtaxa. BioStudies matches the exact facet label only (no subtaxa) and refuses a
CURIE under `--in`. To pin a taxon, resolve it first:
`quarry term search "homo sapiens" --in ncbitaxon --exact`, then pass the `ncbitaxon:` CURIE it prints.

### Gene Expression Omnibus (`geo`)

Roles: repository. Prefixes: `geo`.

- rest `https://eutils.ncbi.nlm.nih.gov/entrez/eutils`: every 0.34 s (0.1 s with a key); key NCBI_API_KEY (optional-key); page cap 10000; reports a total
- rest `https://www.ncbi.nlm.nih.gov/geo/query`: every 0.34 s; no total

- esearch serves at most 10,000 ids per query without the history server. Handling: a count above the window is refused with too_many_results before any summary request; -n inside the window is served.
- a SuperSeries repeats its SubSeries' samples, so a naive harvest counts them twice. Handling: show reads the brief SOFT text and lists SuperSeries/SubSeries relations as geo: cross-references; GEO's sentence stays in the summary.
- suppl/filelist.txt is missing for many series and no checksum is published. Handling: files reads !Series_supplementary_file lines from the brief text (NONE means no files) and serves the HTTPS mirror of each FTP path; checksums stay unset.
- a series names several papers. Handling: the first PubMed id is the publication, the rest are xrefs, and the search report warns.
- Entrez drops a term it has no records for (or a field tag it does not know) and answers for the rest, never widening the query. Handling: esearch reads errorlist and warninglist; each term Entrez found nothing for or ignored becomes a warning in the search report, in NCBI's spelling.
- a supplementary file line may name a URL outside ftp.ncbi.nlm.nih.gov or one quarry cannot read. Handling: files fails the whole call with upstream_failed naming the URL (or saying a line could not be read) rather than listing the rest; no file is silently dropped.

### European Nucleotide Archive (`ena`)

Roles: repository. Prefixes: `bioproject`, `insdc.sra`.

- rest `https://www.ebi.ac.uk/ena/portal/api`: every 0.5 s; reports a total
- rest `https://www.ebi.ac.uk/ena/taxonomy/rest`: every 0.5 s; no total

- a wildcard cannot contain '-', '.' or a space, and matches substrings (ARP1 finds PARP1). Handling: phrases compile to exact-equality clauses on study_title and study_description; no wildcard is generated.
- the search endpoint can answer an incomplete listing during an outage. Handling: every search also asks the count endpoint and fails when the listing is shorter.
- the count endpoint returns HTTP 500 under load. Handling: the client retries 5xx with backoff, then the search fails rather than report no count.
- tax_eq matches one taxon node, and tax_tree, which includes subtaxa, takes ids only. Handling: --organism includes subtaxa: an ncbitaxon: CURIE compiles to tax_tree; a name is first resolved through the taxonomy service's any-name lookup, refused when it names no taxon (not_found) or several (ambiguous_id).

### BioStudies (`biostudies`)

Roles: repository. Prefixes: `biostudies`, `arrayexpress`.

- rest `https://www.ebi.ac.uk/biostudies/api/v1`: every 0.5 s; page cap 100; reports a total

- phrase queries expand through EFO synonyms with no off switch. Handling: coverage says match: expanded; --exact refuses BioStudies, so an exact biology search names its resources with --in.
- search hits omit the organism. Handling: --organism becomes the facet.organism parameter (a taxon name) and every hit then carries it; an ncbitaxon: CURIE skips biostudies from a default set and is refused under --in; show reads the study's Organism attribute.
- totalHits is an estimate on large result sets (isTotalHitsExact: false). Handling: an inexact total is reported as null and the listing pages to a short page (complete: short-page).
- E-GEOD-n is the GEO import of GSEn, and S-EPMCn holds a paper's supplementary files. Handling: arrayexpress:E-GEOD-n carries a geo:GSEn cross-reference; biostudies:S-EPMCn carries pmc:PMCn as its publication.
- search also returns studies of the BioModels (MODELn, BIOMDn) and EMPIAR (EMPIAR-n) collections. Handling: they keep their own archives' ids, biomodels.db:MODELn and empiar:n, as cross-reference-only CURIEs; an accession of any other shape is upstream_failed naming it.
- a study's file list mixes files and directories, and <httpLink>/Files/<path> does not serve a directory. Handling: files lists a directory with media_type inode/directory and its ftp location only; --acquisition refuses it by name with unsupported_transport unless --file leaves it out; an entry with no type, or a type other than file or directory, is upstream_failed.
- a study may hold its files in File List attributes rather than inline (S-BIAD144: none inline, 223 in 'File list_1.json'), and the lists of large studies run to hundreds of MB. Handling: files follows each section's File List at <httpLink>/Files/<name> and fails incomplete_listing when the entries listed differ from info.files; a study needing file lists with more than 10,000 files is refused with too_many_results, naming the lists, before any is read.
- facet.organism matches one exact label, so a taxon's subtaxa are not included. Handling: biostudies stays in an organism search, and the report warns that it matched the label only.

### Gene Ontology (`go`)

Roles: ontology. Prefixes: `go`.

- rest `https://www.ebi.ac.uk/ols4/api/ontologies/go`: every 0.5 s; page cap 100; reports a total

- OLS returns OBO-cased ids (NCBITaxon:9606) and cross-reference databases refs may not know. Handling: every id is re-parsed to its canonical CURIE; an unparsable primary id fails with upstream_failed, an unparsable cross-reference is left out and named in warnings.
- OLS _links hrefs are http://. Handling: the adapter builds every URL from the route's https base and never follows a returned link.
- term_replaced_by is a short form (GO_0008150) and consider holds OBO PURLs; an obsolete term's label can be its short form (GO_0000004). Handling: both become CURIEs through obo_text before ids.parse; the label prints as given.
- q is Solr syntax: * and ? are wildcards, a colon makes a field query, () and ~ change parsing, several words are ANDed. Handling: term search refuses Lucene metacharacters, a leading + or -, the words AND, OR and NOT, and a non-CURIE colon (unsupported_filter); the skill says words are ANDed.
- OLS loads go-plus; an obsolete term can carry no term_replaced_by but list consider. Handling: show prints obsolete, replaced_by when given, and consider.
